# 잠금화면 운동 기록

운동 기록 화면의 `기록 메뉴 → 잠금화면 기록`에서 오늘의 개인 운동을 켠다.
현재 미완료 세트의 운동명·순서·무게와 횟수(시간 운동은 시간)를 표시한다.
사용자가 `세트 완료`를 누르는 것이 표시된 수행값의 확인이다. 타이머가 끝난
사실만으로 수행·RIR를 만들지 않는다. 값 수정과 완료 취소는 앱에서 한다.
트레이너가 대신 입력하는 회원 기록·수업 과제는 다른 저장 권한을 사용하므로
이 개인 기록 알림에 포함하지 않는다. 웹과 지원하지 않는 OS에는 메뉴가 없다.

Android는 기존 휴식 타이머 서비스의 같은 알림에서 세트와 휴식을 전환한다.
iOS 17 이상은 실시간 현황과 LiveActivityIntent를 사용한다. 기기 알림·실시간
현황 권한이 꺼져 있으면 실제 설정 화면으로 안내한다. 잠금 중 인증 요구와
실제 잠금화면 표시는 기기의 OS·보안 설정을 따르며 실기기 확인이 필요하다.

## 저장과 복원

Flutter가 정지·종료된 상태에서도 네이티브가 **확인한 실제 값과 완료 시각**을
내구성 있는 기록 보관함에 먼저 저장한다. Android는 동기 SharedPreferences
트랜잭션, iOS는 App Group의 파일 잠금·원자 교체를 사용한다. 성공 후에만
다음 세트와 휴식 시각을 표시한다. Hive 파일은 네이티브가 직접 수정하지 않는다.

앱은 초기화·복귀·재발행 전에 소유자·날짜·유효 기간·세트 값 지문·차례를
확인하고 완료 기록만 적용한다. 계정별 스냅샷의 처리 영수증과 수행값을 저장한
뒤 네이티브 보관함을 확인 처리한다. 중복 탭·저장 직후 종료·확인 응답 실패에도
같은 완료가 취소되거나 두 번 적용되지 않는다. 게스트 소유자는 기기별 고정 키다.
로그아웃은 표시를 지우되 미확인 수행 기록을 다른 계정에 넘기거나 삭제하지 않는다.

앱에서 세트를 변경·삭제한 경우 원문 기록을 덮어쓰지 않고 보관한다. 사용자가
앱 기록을 유지하거나 별도 수행 기록으로 복원하는 선택으로 충돌을 해결한다.
표시 내용이 바뀔 때 새 세션 세대를 발급해 오래된 알림을 거절하고, 완료를
취소한 세트는 새로운 세대로 다시 체크할 수 있다.

## 검증과 iOS 배포

Flutter의 저장·중복·소유권·충돌 회귀, Android 네이티브 알림·저장 회귀,
macOS의 서명 없는 iOS 앱·확장 빌드와 시뮬레이터 저장 테스트를 검증한다.
실제 iPhone의 잠금·Face ID 동작은 시뮬레이터 빌드 통과로 확정하지 않는다.
Apple Developer 팀·App Group 등록·서명 설정을 연결하기 전에는 TestFlight나
App Store 설치용 iOS 배포가 이루어지지 않는다. 그룹 ID는
`group.com.teampara.setflow`, 확장은 `com.teampara.setflow.WorkoutLiveActivity`다.
