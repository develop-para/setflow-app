# 운동 추천과 세트 편집

운동 기록·추천 변경은 [근거 검토 정책](workout-evidence-policy.md)을 따른다.
`lib/domain/workout_design_rule.dart`에서 연구 원칙, 앱 수치의 선택 이유, 관찰값 보존과
적용 한계를 구분한다. 논문 링크나 회귀 통과만으로 개인별 최적성·안전성이 검증되지는 않는다.

## 세트별 다음 목표 (1.28.0)

추천의 반복 범위와 실제 등록할 세트별 목표 횟수를 분리한다. 최근 같은 종목·같은 중량의
일반 작업세트를 사용하며 `10 / 9 / 8회`를 충분히 완료했다면 `11 / 10 / 9회`를 제안한다.
목표는 기존 목표 범위 안으로 제한한다. RIR를 기록한 경우 2 이상 10 이하일 때만 증가하고,
기록하지 않은 경우 완료 기록으로 진행하되 개인의 반복 여유를 확인했다는 의미는 아니다.
불완전한 기록·반복수 하락·휴식 변화(15초 초과)는 증가를 보류한다. 새 세트를 추가한 날은
횟수까지 함께 늘리지 않는다. 피로·4주 초과 중단·증량·감량은 기존 중량 조정과 하한 목표가 우선이다.
같은 중량에서 충분한 전체 작업세트가 목표 상단을 두 번 연속 달성하면 기존 증량 규칙을 적용한다.

추천 화면, 수동 운동 추가, 추천 수락, 추천 적용은 같은 세트별 목표를 사용하고 시간 예산에도
실제 목표 횟수를 반영한다. 완료 기록은 다시 쓰지 않는다. 개인 코칭을 켠 본인 작성 루틴은
적용 시 작업세트 무게·횟수를 개인 기록으로 갱신한다. 저장된 원본, 웜업, 트레이너·외부 루틴은 보존한다.

점진적 과부하 방향은 [ACSM 2009](https://pubmed.ncbi.nlm.nih.gov/19204579/)를 참고했으며,
세트별 +1회와 비교 조건은 앱의 보수적인 운영 규칙이다. 논문이 이 알고리즘의 개인별 최적성을 검증한 것은 아니다.

## 사용자 흐름

- 첫 운동 추천 전에 **오늘 운동 부위**를 선택한다. 복수 선택, 3분할(가슴·어깨·삼두 / 등·이두 / 하체·복근), 5분할(가슴 / 등 / 하체 / 어깨 / 팔) 빠른 선택을 제공한다.
- **완전 추천**은 부위 제한 없이 목표·기록·운동량을 사용한다. 특정 분할 방식의 우월성을 전제하지 않는다.
- 선택은 `WorkoutSession.trainingFocus`에 날짜별로 저장한다. `null`은 미선택, 빈 집합은 완전 추천이다. 아직 운동이 없는 날짜도 기기 스냅샷에 남고, 다음 날에는 복사하지 않는다.
- 진행 중 부위 변경은 기록 메뉴의 **오늘 부위**에서 한다. 세트 완료 시 설문을 자동으로 열지 않는다.
- 시작할 때 부위와 함께 **오늘 운동 시간**(제한 없음 / 15·30·45·60·90분)을 선택할 수 있다. 취소하면 부위와 시간 모두 저장하지 않는다. 기록 메뉴의 **시간·추천 설정**에서 나중에 바꿀 수 있다.
- 추천의 **주 장비 사용 불가**는 그날만 장비를 제외하고, 검토된 같은 동작의 후보로 대체한다. **오늘만 건너뛰기**는 그날의 종목만, **앞으로 추천에서 제외**는 이후 날짜에도 적용한다. 시간·추천 설정의 **다시 추천**으로 복원한다. 시트를 그냥 닫거나 직접 선택하는 것은 거절·비선호로 기록하지 않는다.
- 정밀 추천 설문은 사용할 장비를 직접 선택해야 저장된다. 새 설문에서 맨몸을 자동 선택하지 않고, 기존 장비 선택은 유지한다. 운동 선택 화면의 **추천 장비 → 변경**에서 실제 사용할 장비를 확인·수정한다. 목록의 기구 검색 필터는 추천 장비 설정을 바꾸지 않는다. 제외 후 후보가 없어도 **장비·추천 정보 수정**으로 바로 돌아가 저장 후 재추천할 수 있다.
- 추천 ON 상태에서 운동 선택 화면의 **운동 추천**을 누르면 앱의 기본 추천 계획 안팎에서 바로 다음 후보를 제안한다. 기본 계획을 넘었다는 이유로 확인 창을 먼저 띄우지 않는다. 실제 최종 제안 세트가 남은 기본 계획을 넘을 때만 직접 요청한 추가 추천임을 표시한다. 장비·숙련도·통증·제외 동작·선택 부위·제외 종목·시간 조건은 계속 적용하고 기존 기록은 변경하지 않는다.
- 세트 완료에 따라 자동으로 이어지는 추천은 기본 계획에 도달하면 멈춘다. 완료량과 오늘 미완료 계획도 포함한 집계를 안내하며 사용자는 **운동 추천**을 직접 눌러 계속 요청할 수 있다. 추가 허용은 그 요청에만 적용하고 설정에 저장하지 않아 다음 자동 추천은 기본 계획을 다시 적용한다. 후보나 시간이 없으면 해당 이유와 수정 경로를 안내한다.
- 추천 이유는 요약과 **동일 종목의 완료 기록 날짜 수**를 먼저 보여준다. 두 날짜 미만이면 `기록 부족`으로 표시한다. 전체 이유·적용 범위·논문은 펼쳐 볼 수 있다. 이 표시는 확률이나 개인의 안전성을 보증하는 점수가 아니다.
- 무게 다이얼의 **적용** 즉시 뒤의 가벼운 일반 세트만 같은 무게로 올린다. 더 무거운 계획, 완료한 기록, 웜업·드랍 세트는 보존한다. 되돌리기는 전파한 값만 취소하며 이후 완료하거나 다시 수정한 값은 보존한다.

## 추천 순서

1. 검토된 카탈로그와 사용자가 추천 정보를 작성하고 참여를 켠 내 운동에서 기존 종목·사용자가 제외한 종목을 빼고, 장비·숙련도·제외 동작 조건을 적용한다.
2. 선택한 **주동근**을 필수 조건으로 적용한다. 벤치 프레스의 보조근이 삼두라고 해서 삼두 선택에 벤치 프레스를 끼워 넣지 않는다.
3. 이번 주 월요일부터 오늘까지의 완료량과 오늘 계획으로 남은 운동량을 계산한다. 지난주, 미래, 과거의 미완료 계획, 웜업, 예시 기록은 제외한다. 오늘 세션이 기록 목록에도 있으면 한 번만 센다. 지난주 기록은 주간 예산을 소비하지 않지만 중량·횟수와 수행 추세를 참고할 때 계속 사용한다.
4. 진행하던 부위의 후보를 우선한다. 복합 운동을 앞에 배치하고 같은 부위의 복합 운동 두 개 이후에는 보조 운동을 우선한다. 최근 같은 종목의 기록이 있으면 진행을 추적할 수 있도록 우선한다. 날짜만 바뀌었다고 종목을 임의 순환시키지 않는다.
5. 조건에 맞는 운동이 없으면 추천을 끝내고, 기본 계획이 찼으면 세트 완료에 따른 자동 추천만 끝낸다. 명시적인 **운동 추천** 요청은 기본 계획을 넘어 제안할 수 있다. 다른 부위로 조건을 풀지 않으며 사용자는 직접 운동·세트를 추가할 수도 있다.

## 시간·대체·선호

- 시간은 완료한 기록과 이미 추가한 미완료 계획을 먼저 예약한다. 준비·종목 전환 90초, 반복당 4초, 버티기 기본 60초와 설정된 세트 간 휴식을 합산한다. 마지막 세트 뒤의 휴식은 빼고, 종목을 더하면 이전 마지막 휴식을 다시 포함한다. 오늘 진행 중인 기록은 실제 경과 시간 + 남은 계획과 전체 계획 추정치 중 큰 값을 사용한다.
- 남은 시간에 맞춰 **새 추천의 세트만** 줄인다. 한 세트도 들어가지 않으면 후보에서 제외한다. 기록이나 수동 계획을 자동으로 삭제·축소하지 않는다. 지속 유산소는 준비 시간을 뺀 뒤 분 단위로 줄이며 최소 5분을 확보한다. 인터벌 구조를 임의로 자르지 않는다. 거리는 원래 같은 종목 기록으로 추정된 경우에만 시간 비율로 조정한다.
- 시간 계산은 제품의 추정 규칙이다. 실제 동작 속도·기구 대기·운동 전 준비를 정확히 예측하지 않는다. 시간 예산과 건너뛰기는 날짜별이며 다음 날로 복사하지 않는다.
- 대체 후보 연결표는 `ExerciseSubstitutions.groups` 한 곳이다. 같은 부위여도 벤치프레스를 플라이로 바꾸거나 수직 당기기를 로우로 바꾸지 않는다. 장비·숙련도·명시한 제외 동작·선택 부위·시간 조건을 유지하며 자동/명시적 요청의 기본 계획 적용 방식도 유지한다. 대체 종목 자체의 기록이 없으면 첫 중량은 직접 선택한다. 동등한 후보가 없으면 직접 선택을 안내한다.
- 사용 불가 버튼에는 제외할 주 장비 이름을 표시한다. 그 장비가 필요한 다른 후보도 그날 제외한다. 현재 일반 머신은 개별 기구가 아닌 `일반 웨이트 머신 구역` 단위이므로 그 범위로 표시·제외한다. 맨몸 종목에는 기구 사용 불가 버튼을 표시하지 않는다.
- 직접 운동 목록에서 추가한 종목은 **서로 다른 날짜**로 기억한다. 최근 90일 내 두 날짜 이상 선택했을 때 우선순위에 반영하며, 종목별 최근 8개 날짜만 보관한다. 같은 날 반복 추가·추천 수락·루틴 불러오기는 선호를 부풀리지 않는다. 미래 날짜의 선택은 그 날짜 전 추천에 반영하지 않는다. 부위·운동량·동작 우선순위와 모든 필수 조건이 선호보다 먼저다.

## 직접 만든 운동의 추천 참여

- **새 운동 만들기**는 이름·부위·기록 방식만 받는다. 추천 정보 입력을 요구하거나 생성 직후 설문을 열지 않는다. 기존에 만든 운동도 계속 직접 추가해서 사용할 수 있다.
- 운동 선택 화면 상단의 **내 운동 추천 정보**, 또는 내 운동 행의 **추천 정보 설정**에서 별도로 작성한다. **자동 추천에 포함**을 켜고 저장할 때만 추천 후보에 들어간다.
- 저항운동의 필수 정보는 주로 쓰는 부위(팔은 이두·삼두 구분), 동작 유형, 필요한 장비, 필요한 운동 경험이다. 기존 부위와 모순되는 주동근·동작은 저장하지 않는다. 시간 버티기는 몸통 버티기 또는 그 외 동작으로 한정한다. `기타` 부위는 주동근을 명시해야 한다.
- 유산소는 주동근·저항운동 동작 대신 지원하는 **유산소 종류**를 선택한다. 선택한 종류의 시간·거리 지표를 사용하지만, 거리 기준은 해당 내 운동 ID의 실제 기록만 사용한다. 다른 달리기·로잉 종목의 속도를 가져오지 않는다.
- 함께 들어가는 제외 동작과 복합 운동의 보조 부위는 선택 정보다. 보조 부위는 작성한 것만 0.5로 반영한다. 동작 유형에 해당하는 기본 제외 동작은 자동 적용되고, 작성한 추가 동작도 함께 적용된다. 밴드·케틀벨·스미스 머신도 장비에 포함한다.
- 이름만 보고 부위·장비·동작을 추측하지 않는다. 이 정보는 사용자 작성 정보이며 검토된 공통 카탈로그로 승격하지 않는다. 추천 이유에도 사용자 작성 정보임을 표시한다. 정밀 추천 프로필을 작성하지 않은 상태에서는 입문 가능한 것으로 지정한 내 운동만 추천한다.
- 기존 시간·부위·장비·숙련도·제외 동작·날짜별/영구 제외 조건과 자동/명시적 요청의 기본 계획 적용 방식을 그대로 적용한다. 동작 대체는 작성한 유형이 같을 때만 허용하고 `그 외 동작`은 자동 대체하지 않는다. 다른 종목의 중량을 재사용하지 않는다.
- **자동 추천에 포함**을 끄면 후보에서 빠지고 운동·완료 기록·루틴·작성한 정보는 남는다. 저장 전 뒤로 가기는 변경을 취소한다. 정보가 없는 기존 운동이나 손상된 선택 필드는 수동 사용을 유지하면서 자동 추천에서 제외한다.
- 정보는 기존 개인 스냅샷의 `ExerciseTemplate.customRecommendation`으로 저장한다. 게스트 기기 재시작, 계정 동기화, 명시적 게스트 가져오기에서 유지하고 계정을 바꾸면 해당 계정의 내 운동만 남긴다. 추천 정보 변경은 기록의 수치·세트와 코칭 출처를 보존한다.

## 자동 추천의 기본 계획

개인 코칭 베타를 켜면 주간 목표와 부위별 하루 예산을 개인 기록으로 조정한다.
계산 규칙·기록 부족 처리·검증 범위·이후 구독 권한 연결은 [개인 코칭](personal-coaching.md)을 따른다.
아래 표는 개인 코칭을 끄거나 개인 기록이 부족할 때의 시작 계획이다. 정보가 부족한 상태에서
세트 완료 때마다 새 운동을 끝없이 자동으로 추가하지 않으려는 제품 선택이다. 정확한 숫자와
숙련도별 간격을 논문이 정한 것은 아니다. **운동 추천**을 직접 요청하면 이 계획을 넘어 제안받을 수 있다.

| 항목 | 입문 | 기본(숙련도 미입력 포함) | 숙련 |
|---|---:|---:|---:|
| 종목 작업세트 | 2 | 복합 3, 보조 2 | 복합 3, 보조 2 |
| 부위별 하루 자동 추천 계획 | 4 | 6 | 8 |
| 근비대 목표 주간 계획(월요일부터) | 8 | 12 | 16 |
| 그 외 목표 주간 계획(월요일부터) | 6 | 10 | 10 |
| 하루 전체 저항운동 자동 추천 계획 | 12 | 18 | 24 |

건강 목표의 복합 운동은 기존 2세트 기본값을 따른다. 오늘 피로 설문을 선택하면 종목당 1세트를 줄인다. 자동 추천은 남은 계획이 더 작으면 그만큼만 추가한다. 명시적 추천 요청은 남은 계획에 맞춰 세트를 강제로 줄이지 않지만 피로·기록·시간 조정은 적용한다. 수동 추가는 최소 1세트를 허용하며 사용자가 지정한 세트 기본값도 유지한다.

주동근은 1, 검토된 복합 운동의 보조근은 0.5로 합산한다. 팔은 이두와 삼두를 구분한다. 이는 실제 근활성 측정값이 아니다. 대분류인 하체의 여러 근육을 각각 독립적으로 처방하는 모델도 아니다. 정확한 예산 숫자는 **제품 기본값**이며 개인별 최적량이나 생리적 상한으로 해석하지 않는다.

## 반복·중량

- 근력: 경험 있는 사용자의 복합 운동 4–6회. 입문자·보조 운동 8–12회.
- 근비대: 복합 8–12회, 보조 10–15회. 이 범위만 효과가 있다는 뜻은 아니다.
- 근지구력: 15–20회. 건강·감량 목표의 저항운동: 8–12회.
- 휴식: 근력 복합 180초, 그 외 복합 120초, 보조 90초. 수정 가능하다.
- 시작 중량은 **같은 종목의 실제 일반 완료 세트**에서 가장 자주 쓴 무게를 택한다(동률이면 낮은 무게). 11회 이상 기록도 실제 중량 기준으로 재사용하며 불확실한 e1RM 변환을 거치지 않는다.
- 같은 무게에서 목표 세트 수 이상을 완료하고 모든 세트가 반복 상단을 달성한 날이 두 번 이어지면 한 단계 올린다. RIR이 기록됐다면 모든 해당 세트에서 최소 2회 여유가 있어야 한다. 두 날짜가 28일 넘게 떨어지면 연속 성공으로 보지 않는다. 기구별 실제 증분은 사용자가 확인하며 앱의 증가폭은 10%를 넘지 않는다.
- 두 번 연속 같은 무게에서 두 세트 이상 최소 반복에 미달하면 약 5%, 동일 종목의 마지막 기록이 28일보다 오래됐거나 오늘 피로 응답이 있으면 약 10%를 감량 기준으로 쓴다. 이는 앱의 조정 기준이며 정확한 감량 폭을 논문이 검증한 것은 아니다. 0.5kg 단위로 내림하므로 실제 변화율은 기준과 다를 수 있어 전후 kg을 표시한다. 내림하면 0kg이 되는 양수 기록은 기존 중량을 유지한다. 중량 감량 사유가 겹쳐도 중복 적용하지 않는다.
- 성공·미달은 서로 다른 날짜를 비교한다. 같은 날짜의 사본이나 여러 종목 행은 한 날짜로 합친다. 연속 미달 역시 두 기록 사이가 28일 이내여야 한다.
- 최근 네 날짜가 42일 안에 있고, 각 날짜에서 같은 중량의 일반 완료 세트가 기본 처방 세트 수 이상일 때만 추가 추세를 판단한다. 각 날짜의 처음 기본 세트 수만큼 평균 반복을 비교한다. 세 번 연속 1회 이상 줄었고 기존 증량·감량 조건에 해당하지 않으면 중량은 유지하고 새 처방을 1세트 줄인다. 네 번 모두 반복 범위 안에서 상단 미만이며 평균 차이가 1회 이내면 정체로 표시하고 중량을 유지한다. 부분 기록·서로 다른 중량·오래된 기록으로 추세를 만들지 않는다.
- 동일 종목의 기록이 28일보다 오래되면 약 10% 기준의 중량 조정과 함께 새 처방을 1세트 줄인다(최소 1세트). 이는 해당 종목 기록의 공백이며 운동 전체를 중단했다는 판단이 아니다. 자동 판단으로 통증·피로를 진단하거나 기존 계획을 덮어쓰지 않는다. 네 날짜·42일·1회·1세트는 논문에서 개인에게 검증한 수치가 아니라 앱 기본값이다.
- 기록이 없는 종목은 kg을 지어내지 않고 **중량 직접 선택**으로 표시한다. 맨몸·시간 운동은 중량 추천에서 제외한다. 실제 RIR은 사용자 입력이며 다음 세트로 복사하지 않는다.
- 기본 세트·횟수를 직접 지정했다면 새로운 종목의 수동 추가에서 그 값을 우선한다. 기록 기반 추천과 자동 추천은 위 규칙을 적용한다.

## 연구와 적용 범위

앱 적용 규칙 재검토일: 2026-10-14. 출처별 공식 초록/본문 확인 범위는 [근거 검토 정책](workout-evidence-policy.md)을 따른다. 아래 논문은 앱의 관련 논문 화면에서도 공식 링크·적용 규칙·한계와 함께 열 수 있다.

- [Currier et al., ACSM 2026](https://pubmed.ncbi.nlm.nih.gov/41843416/), DOI `10.1249/MSS.0000000000003897`: 목표에 따라 부하와 주간 운동량을 구분한다. 개인 kg이나 이 앱의 예산 수치를 결정한 연구는 아니다.
- [Pelland et al., 2026](https://pubmed.ncbi.nlm.nih.gov/41343037/), DOI `10.1007/s40279-025-02344-w`: 직접·간접 세트를 구분한 메타회귀를 참고해 보조근을 절반으로 합산한다. 집단의 용량 반응과 수익 체감은 개인별 최적량을 확정하지 않는다.
- [Ramos-Campo et al., 2024](https://pubmed.ncbi.nlm.nih.gov/38595233/), DOI `10.1519/JSC.0000000000004774`: 운동량을 맞췄을 때 분할·전신 방식의 근력과 근비대 차이가 뚜렷하지 않았다. 선호하는 분할을 선택하게 한 근거이며 특정 3·5분할 조합의 검증은 아니다.
- [ACSM 2009](https://pubmed.ncbi.nlm.nih.gov/19204579/), DOI `10.1249/MSS.0b013e3181915670`: 반복 수행에 따른 점진적 부하 증가 원칙. 두 차례 상단 달성·RIR 조건·감량 비율은 보수적인 앱 구현이다.
- [Nunes et al., 2021](https://pubmed.ncbi.nlm.nih.gov/32077380/): 우선 운동을 앞에 배치한다. 앱의 개별 종목 연결표가 논문에서 비교된 것은 아니다.
- [Grgic et al., 2018](https://pubmed.ncbi.nlm.nih.gov/28933024/): 근력 훈련의 충분한 세트 간 휴식 원칙. [Refalo et al., 2023](https://pubmed.ncbi.nlm.nih.gov/36334240/): 모든 세트를 실패 지점까지 수행하도록 강제하지 않는다. 2–3회 여유 안내는 조절 가능한 기본값이다.
- [Singer et al., 2024](https://pubmed.ncbi.nlm.nih.gov/39205815/), DOI `10.3389/fspor.2024.1429789`: 근비대의 휴식시간 직접 메타분석을 근비대 추천에 연결한다. 60초 초과의 작은 이점을 시사하지만 90초 초과 추가 이점은 불명확하며, 숙련자·몸통 근육 자료도 부족하다. 정확한 90/120/180초 기본값을 새 최적값으로 바꾸는 근거는 아니다.
- [Robinson et al., 2024](https://pubmed.ncbi.nlm.nih.gov/38970765/), DOI `10.1007/s40279-024-02069-2`: 근비대와 근력의 실패 근접도 관계가 다를 수 있음을 근비대 추천에 반영한다. 추정 RIR의 탐색 메타회귀이며 개인의 최적 RIR은 확정하지 않는다. [Halperin et al., 2022](https://pubmed.ncbi.nlm.nih.gov/34542869/), DOI `10.1007/s40279-021-01559-x`: RIR은 사용자의 주관적 예측이고 정확한 실측값이 아니므로 자동 복사나 평균 오차의 일괄 보정을 하지 않는다.
- [Craven et al., 2022](https://pubmed.ncbi.nlm.nih.gov/35708888/): 수면 부족에 따른 수행 저하 가능성을 참고한다. 앱의 정확한 감량 폭이나 부상 예방 효과를 검증한 연구는 아니다. [Larsen et al., 2021](https://pubmed.ncbi.nlm.nih.gov/33520457/): 수행·주관적 여유에 따른 조정 접근의 근거이며 앱의 개인별 최적량을 검증하지 않았다.
- [Hickmott et al., 2022](https://pubmed.ncbi.nlm.nih.gov/35038063/), DOI `10.1186/s40798-021-00404-9`: 개인 코칭을 적용한 추천에서만 자율조절과 고정 부하의 비교 근거를 연결한다. 고정 부하보다 우월하다고 확정하지 않으며 속도손실 운동량 조절을 앱의 주간 ±2세트와 같게 보지 않는다.
- [Cox et al., 2026 권호·2025 온라인](https://pubmed.ncbi.nlm.nih.gov/41430613/), DOI `10.1186/s12966-025-01868-8`: 모바일 저항운동 안내와 처방 설명의 설계 근거다. 숫자 처방의 직접 근거로 붙이지 않으며 이 앱·개인화 추천·특정 UI·지속 참여의 효과를 검증한 연구가 아니다.

추가 검색은 [근거 검토 정책](workout-evidence-policy.md)의 선정·보류 이유와 공식 초록/본문 확인 범위를 따른다.
기존 고찰과 원연구가 중복될 수 있어 논문 수를 독립적인 참가자 자료나 효과 확신도로 합산하지 않는다.
이번 보강은 근거 연결·설명의 적용 범위를 개선하며 정확한 세트·반복·휴식·RIR 수치를 변경하지 않는다.

### UI/UX 점검 (2026-10-14)

운동 기록·추천·설정·관련 논문 화면을 우선 점검하고, 캘린더·루틴·통계·마이 설정의 탐색과 기존 회귀도 검토했다.
아래는 재현 경로를 확인해 수정한 문제다. 소스·위젯 검사와 실기기 사용성 검증은 구분한다.

근거 검색 입력은 목록 위에 유지해 긴 설명을 읽은 뒤나 키보드가 열린 작은 화면에서도 다시 검색할 수 있다.
공식 링크 열기·검색 초기화·추천 출처 필터 유지와 기존 기록 보존을 함께 검사한다.
실기기의 제스처·스크린리더·장기간 대량 기록의 모든 화면 조합을 이번 검사로 확인했다고 주장하지 않는다.

`ResistancePrescriptionEngine`은 부위 분류·운동량·반복·중량 계산을, `ExerciseRecommendationEngine`은 후보 선정을 담당한다. 화면은 `AppState`를 통해 호출한다. 앱 저장소 포트와 기존 JSON 스냅샷을 사용하며 신규 서버 API나 외부 AI 호출은 없다.

시간·날짜별 제외·사용 불가 장비는 `WorkoutSession`, 영구 제외·직접 선택 날짜는 `RecommendationPreferences`로 기존 스냅샷에 저장한다. 선택만 한 빈 날짜도 보존하며 게스트 기기 저장, 계정별 동기화, 명시적인 게스트 가져오기에서 유지한다. 필드가 없는 기존 스냅샷은 제한·제외·선호 없는 기본값으로 읽는다. 계정을 바꾸면 이전 사용자의 선호도 지운다.

회귀: `resistance_prescription_test.dart`(부위 제한, 모든 대안 소진, 운동량, 전파·복원, RIR, 기록 날짜, 게스트 재시작), `training_focus_flow_test.dart`(첫/다음 추천, 분할 선택·취소, 다이얼·되돌리기, 작은 화면·2배 글자·다크 모드), 기존 기록·성능·계정 저장 테스트.

추가 회귀: `advanced_workout_recommendation_test.dart`(누적 시간·실제 경과·유산소·동작 대체·장비·선호·추세·게스트 재시작), `advanced_recommendation_flow_test.dart`(시간 선택·취소·일회/영구 제외·복원·직접 선택·작은 화면/2배 글자/세이프에리어/다크), `account_persistence_test.dart`(신규 설정 동기화와 계정 경계).

내 운동 회귀: `custom_exercise_recommendation_test.dart`(명시적 참여·조건 필터·자체 기록·분류/운동량·대체·JSON/게스트 재시작), `custom_exercise_recommendation_flow_test.dart`(간단한 생성·별도 편집·검증·취소·참여 끄기/복원·유산소·2배 글자/다크/세이프에리어), `account_persistence_test.dart`(새 기기 동기화·계정 전환·명시적인 게스트 가져오기).
