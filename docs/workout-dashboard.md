# 운동 대시보드

## 탐색

- 메뉴의 **대시보드**에서 완료 기록이 있는 모든 종목을 본다. 기본은 전체 기간이고 이번 주·최근 30일·90일을 고를 수 있다.
- 기간은 상단 합계와 종목별 지표 모두에 적용한다. 검색·부위·정렬은 종목 목록에 적용한다.
- 운동 이름·별칭·부위·기구를 검색하고 최근 운동순·많이 한 순·이름순으로 정렬한다. 기록에 남은 종목을 사용하므로 현재 카탈로그에서 빠진 종목도 보인다.
- 종목을 누르면 지표별 추이를 보고, 점을 누르거나 이전·다음 버튼으로 날짜를 선택한다. 날짜별 기록을 펼치면 실제 완료 세트의 중량·횟수·시간·거리를 볼 수 있다.
- 상세에서 돌아와도 검색·기간·부위·스크롤 위치가 유지된다. 게스트도 같은 기능을 사용한다.

## 지표 정의

| 유형 | 지표 |
|---|---|
| 중량 운동 | 최고 중량, 최고 추정 1RM, 누적 볼륨, 최고/누적 반복, 완료 세트 |
| 맨몸 반복 운동 | 최고/누적 반복, 완료 세트 |
| 버티기 운동 | 한 세트 최장 시간, 누적 시간, 완료 세트, 운동한 날 |
| 유산소 | 누적 시간·거리, 평균 페이스, 기록한 구간의 평균 RPE |

- 합계와 최고 기록은 **선택 기간의 완료 세트** 기준이다. 웜업도 실제 기록에 포함한다. 미래 날짜, 미완료 계획, `seed_` 예시 기록은 제외한다.
- 운동한 날은 날짜를 중복 없이 센다. 하루에 같은 종목이 여러 번 등장하면 합친다. 그래프는 날짜별 최고 중량·반복·추정 1RM, 날짜별 합계 볼륨·유산소 시간·거리, 버티기는 날짜별 최장 세트를 표시한다.
- 근력 볼륨은 중량 × 반복의 합이며 `kg·회`(설정 단위에 따라 변경)다. 유산소와 맨몸·버티기 운동을 중량 볼륨으로 계산하지 않는다.
- 추정 1RM은 기존 `PerformanceEngine`과 사용자 설정 공식을 사용한다. 1–10회 일반 완료 세트만 대상으로 하며, 계산할 기록이 없으면 값을 만들지 않는다. 고반복 기록도 나머지 지표와 기록 목록에는 포함한다.
- 평균 페이스는 **시간과 거리가 함께 있는 유산소 구간**의 총 시간 ÷ 총 거리다. 거리 없는 구간을 분자에만 더하지 않는다. RPE 0은 미기록이며 평균에서 제외한다. 기록이 없는 거리·페이스·RPE는 `미기록`으로 표시한다.
- 직전 대비는 선택 기간에서 바로 이전 유효 기록과의 차이다. 운동마다 부하·기구·목표가 다르므로 종목 사이의 점수나 성장 순위를 만들지 않는다.

## 구현과 검증

`WorkoutAnalyticsEngine`이 집계하고 `AppState.workoutAnalytics`로 화면에 제공한다. 기존 세션을 읽으며 서버 스키마나 저장 형식 변경은 없다.

`workout_analytics_test.dart`는 기간 경계·중복 날짜·카탈로그 밖 종목·예시/미래/미완료 제외·고반복·추정 공식·유산소 페이스를 검증한다. `workout_dashboard_test.dart`는 게스트 진입·검색/필터/정렬·전체 목록·실시간 수정 반영·상세 차트/세트·320px/2배 글자/다크 모드를 검증한다.
