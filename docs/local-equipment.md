# 내 기구와 오프라인 운동 목록

## 사용 경로

- `운동 선택 > 내 기구 · 사진과 백업`에서 기구를 등록한다.
- 브랜드·모델 검색으로 제조사 제품을 골라 이름·부위를 채우거나 직접 입력한다.
- 카메라 또는 앨범 사진 한 장, 기구 이름, 브랜드, 모델, 헬스장·좌석·그립 메모를 저장한다.
- `오늘 운동에 추가`로 해당 기구의 독립된 운동 기록을 시작한다.
- 기록 화면의 종목 메뉴 `기구 사진·설정`에서 사진과 설정을 다시 연다.
- `사진 포함 백업`으로 JSON 파일을 저장하고, 새 기기에서 `백업 복원`으로 가져온다.
  모바일은 시스템 공유창의 파일 저장 기능, 데스크톱은 저장 위치 선택, 웹은 다운로드를 쓴다.

## 저장과 복원 계약

기기 소유 자료다. 로그인 없이 저장하며, 계정 전환에도 기구 목록은 유지된다.
`LocalEquipmentRepository`가 포트이고 `HiveLocalEquipmentRepository`가 구현이다.
앱 전용 Hive box `setflow_local_equipment_v1`의 `library` 키에 사진 원본 대신 최적화한
사진 바이트를 넣는다. 임시 카메라 경로를 참조하지 않으므로 캐시 청소 뒤에도 유지된다.
카메라 취소는 기존 사진을 유지하며, Android picker 복구 데이터는 등록 화면에서 회수한다.

사진·브랜드 필드·모델 필드·개인 메모는 계정 스냅샷에 들어가지 않는다. 운동에 사용한 기구의
표시 이름·부위·측정 방식은 운동 기록의 일부로 기존 기록 저장 정책을 따른다. 사진 백업 없이
다른 기기에서 운동 기록을 열어도 종목이 사라지지 않도록 최소 종목 정보를 함께 저장한다.
사진은 커뮤니티나 서버 스토리지에 업로드하지 않는다.

백업 `format=setflow-equipment`, `version=1`은 기구 정보와 base64 사진을 한 파일로 묶는다.
운동 세트·루틴·계정 자료는 포함하지 않는다. 총 64MB, 사진 한 장 4MB, 기구 500개 한도다.
복원은 전체 스키마·ID·사진 헤더·크기를 검증한 다음 저장한다. 같은 ID는 현재 기기 설정을
유지하고 새로운 ID만 추가한다. 잘못된 파일이 기존 목록을 부분적으로 덮어쓰지 않는다.
저장 완료를 기다린 뒤 화면을 닫으며, 읽기 실패 상태에서는 자료 보호를 위해 쓰기를 막는다.
기기 초기화·앱 삭제에 대비하려면 백업 파일을 앱 밖에 보관해야 한다.

## 카탈로그 범위와 출처 (2026-09-13 대조)

자동 추천용 원래 80종은 유지한다. 추가 카탈로그는 사용자 선택용이고 자동 추천의 검수
목록에 끼워 넣지 않는다. `offlineExerciseCatalog`는 원래 80종 + 맨몸 추가 100종 +
제조사별 기구 동작 187개, 총 367개다. 서버 자료는 ID로 합친다.

| 분류 | 선택 가능한 추가 동작 | 대조한 제조사 자료 |
| --- | ---: | --- |
| 테크노짐 퓨어 | 20 | [Pure 카탈로그](https://m.technogymkr.com/web/catalog/16_catalog_pure.pdf), 제품 코드 MG0500 등 |
| 파나타 프리웨이트 스페셜 | 36 | [제품군](https://www.panattasport.com/en/free-weight-special/), [카탈로그 17쪽](https://www.panattasport.com/en/catalog/page/17/), [공식 신제품 자료](https://www.panattasport.com/download/2021/panatta-fw-speciale-new-models.pdf) |

| 해머스트렝스 플레이트 로드 | 37 | [공식 제품 목록](https://www.lifefitness.com/en-us/catalog/strength-training/plate-loaded) |

숫자는 기구 대수가 아니라 **기록 가능한 동작 수**다. 펙덱/리버스 플라이, 어덕션/어브덕션,
어시스트 친업/딥처럼 한 기구의 서로 다른 동작은 별도 ID다. 모든 브랜드의 전 제품·생산연도별
변형을 수집했다는 뜻은 아니다. 일반 종목이나 다른 브랜드의 모델과 ID를 합치지 않는다.
ADVANCE는 `뉴텍 어드벤스`로 표시하고 `어드밴스`와 `Advance`도 검색 별칭으로 제공한다.

주요 부위 표시는 동작 분류다. 기구 이름만으로 특정 근육의 활성도나 우열을 단정하지 않는다.
가슴 상·하부, 등 두께·너비 같은 효과를 제조사 간 동일한 수치처럼 비교하지 않는다.
제품의 실제 궤도와 개인 좌석·그립 설정은 제조사 정보와 사용자 메모로 구분한다.
제조사 이미지·GIF·홍보 설명은 번들에 복제하지 않는다.

맨몸 목록은 기존 [free-exercise-db 고정 원본](https://github.com/yuhonas/free-exercise-db/tree/a859101d633a01c4a1a920d6a8ce41dabba0705f)의
`equipment = body only` **111종 전체**다. 기존 ID로 연결된 11종은 그대로 쓰고 나머지 100종을
한국어 이름·주동근·보조근·기록 방식과 함께 번들에 넣었다. 서버와 동일한 UUIDv5를 사용한다.
철봉·벤치·덤벨·짐볼에 기대는 동작에는 해당 보조 기구 표시를 붙인다. `맨몸` 검색으로는
보조 기구를 쓰는 체중 운동도 찾을 수 있다. 가능한 모든 맨몸 변형의 무한한 목록이라는
뜻은 아니며, 미분류 종목을 임의로 맨몸으로 바꾸지 않는다. 자세한 원본 라이선스와 한국어명
출처는 [운동 카탈로그](exercise-catalog.md)를 따른다.
