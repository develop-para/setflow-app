# 트레이너 직접 관리 회원

트레이너의 **회원 → 회원 추가**에서 이름·휴대폰 번호·관리 메모를 입력한다.
회원의 앱 가입, 센터 등록, 유료 코칭 연결이나 수업 예약은 필요하지 않다.
관리 메모는 등록한 트레이너에게만 보인다. 회원 이름을 누르면 해당 회원의 캘린더가 열린다.

홈의 **회원 기록하기**는 회원 탭으로 바로 이동한다. 직접 등록·센터 배정·앱 코칭 연결 회원을 한 목록에서 찾는다.
동의로 연결한 계정 식별자가 같은 회원만 한 줄로 모으고, 이름·연락처가 같은 별도 회원은 그대로 구분한다.
연결된 기존 수업·과제·대화는 회원 공간의 **회원 정보 → 수업·과제·대화**에서 연다.
앱 코칭 초대와 별도 기록 공유·수정 요청은 회원 화면의 **회원 관리 메뉴**에 있다.

- 빈 날짜 칸을 누르면 그 날짜의 운동 기록 화면이 바로 열린다. 월 이동은 기록 화면을 열지 않는다.
- 기록한 날짜는 종목별 세트·무게·횟수·시간·거리·휴식과 입력한 RIR·RPE를 보여준다.
- 회원별·날짜별 트레이너 원본 하나를 이어서 수정한다. 회원이 직접 남긴 개인 기록은 별도로 조회한다.
- 선택한 날짜의 **운동 기록하기 / 기록 이어서 작성** 버튼은 화면 하단 한 곳에 고정한다.
- 관리 메모 미리보기를 누르거나 **회원 정보**를 열면 전체 메모·정보 수정·앱 연결을 확인한다.
- 숫자는 기존 다이얼, 세트는 기존 순차 스와이프·완료 후 접기를 재사용한다.
- 운동 메모는 회원 앱 연결 후 회원도 본다. 회원 정보의 관리 메모와 구분한다.
- 서버 저장 실패 시 현재 화면의 입력과 요청을 유지해 재시도한다. 앱 종료 후 초안 복원은 지원하지 않는다.
- 같은 기록의 버전이 바뀌면 덮어쓰지 않고 미저장 입력과 최신 원본을 비교한다.

## 회원 앱 연결

트레이너는 회원 공간의 **회원 정보 → 회원 앱 연결 코드**로 일회용 코드를 만든다.
회원은 앱의 **운동 장소 및 센터 → 트레이너 관리 기록 → 트레이너 연결 코드 입력**에서
직접 받은 코드를 입력하고 기록 연결·개인 운동 공유에 동의한다. 이름이나 전화번호가 같다고 자동 연결하지 않는다.

연결하면 회원은 앱 가입 전 트레이너가 기록한 운동도 날짜별로 확인한다.
트레이너의 회원 캘린더에는 회원의 서버에 저장된 과거·앞으로의 개인 기록이 읽기 전용으로 함께 나온다.
기기에만 있는 게스트 기록은 공유하지 않는다. 다른 수업·과제 원본의 별도 동의와 수정 규칙을 바꾸지 않는다.

회원은 기록이 없어도 해당 화면에서 연결을 해제할 수 있다.
해제하면 개인 기록 공유는 즉시 중단되며 트레이너가 남긴 운동 기록은 회원에게 계속 남는다.
원래 회원의 기록이 다른 사람에게 넘어가지 않도록 계정의 연결 이력은 보존한다.
회원 계정이 삭제되어도 트레이너 소유 기록은 보존하며, 그 공간은 다른 계정으로 다시 연결하지 않는다.

## 저장과 권한

`TrainerClientRepository` 포트를 `SupabaseBusinessRepository`의 선택 기능으로 제공한다.
전용 원본은 `trainer_clients`, `trainer_client_workouts`다. 트레이너 개인 스냅샷에 복사하지 않는다.
승인된 담당 트레이너만 회원을 등록·조회·수정하며 회원은 본인이 수락한 기록만 조회한다.
테이블 직접 접근은 차단하고 모든 RPC에서 승인·소유·계정 연결을 확인한다.
수정은 버전 비교, 저장과 초대 수락은 사용자·요청·내용에 묶은 재시도로 중복 반영을 방지한다.

앱과 함께 `supabase/migrations/20261020120000_trainer_managed_clients.sql`을 적용해야 한다.
운영 서버 적용과 앱 배포는 별도 단계다.
